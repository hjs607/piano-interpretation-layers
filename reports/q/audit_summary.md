## 2. 무엇이 바뀌는가

### RQ2 (청취자 층)
- **공유 축은 유지되고 더 선명해진다.** 평가자 보정 후 단위 내 신뢰도: dry→wet 0.89, clean→blurred 0.86, fast→slow 0.75, stable 0.71, rich 0.63, long→short 0.63, cushioned 0.62, flat→spacious 0.54, mellow→raw 0.53, balanced 0.51, **convincing 0.53**(보정 전 0.43). ≥ 0.5 가 7개에서 11개로 는다.
- **"감도는 특성" 은 약하게만 성립.** PDF 의 w 반분 신뢰도 0.47–0.87 은 무표정 렌더·단위 간 분산·척도 사용 습관이 섞인 값이다. 사람 연주·단위 내·평가자별 표준화 후에는 dry→wet 0.51, clean→blurred 0.67, fast→slow 0.61 만 0.5 를 넘고 나머지 공유 축은 0.28–0.44 다. 보정 전 w 는 평가자의 점수 폭과 r = 0.60 — 상당 부분이 "칸을 넓게 쓰는 습관"이었다.
- **"설득력 선호 β" 와 "유형 A·B" 는 철회.** 단위 내·보정 β 의 반분 신뢰도 0.08–0.32. 유형은 BIC 상 k=2 가 낫지만 재실행 일치율 0.60 이라 재현되지 않는다.
- **설득력은 독립 차원이 아니다**(Q8). 평가자에게 선호를 배제하라고 지시한 점(보충자료)과 합쳐, "설득력 = 개인 선호" 라는 해석은 접고 "전반적 평가 요인" 으로 부른다.
- **그래도 개인 층은 실재한다**(Q5). 같은 사람이 다시 들어도 흔들리는 잡음(σ² 0.5–1.3, 점수로 0.7–1.1점)을 빼고도, 평가자×연주 상호작용의 안정 몫이 9차원 모두 0 보다 크고 convincing 에서 가장 크다(0.68, CI 0.47–0.92). 문제는 그 개인차가 **"어느 구간에서 갈리는가"** 로는 잡히지 않는다는 것(Q6).

### RQ3 (겹침)
- **H3c·H3d 는 이 자료로 판정할 수 없다.** 구간별 평가자 간 SD 는 약 10명으로 재면 잡음뿐이고(반분 −0.10), 모의실험상 참 변동계수 0.2 면 0.37 이 나왔어야 하므로, convincing 의 구간 간 "갈림" 차이는 있어도 CV < 0.1 이다. Repp 역설의 "의견이 갈리는 구간" 식 검정은 접는다.
- **갈림은 평가자 수준에서 본다.** H3b(개인 편차 e_ij ~ ρ_j, 평가자별 β^ρ)가 주검정. 다만 Q7·Q8 에 따라 β 는 보정·단위 내 평점으로 추정하고, 유형은 탐색으로만.
- **H3a 는 그대로 진행**: 라벨은 보정값, 특징 6개(`vel_range` 제외) 백색화. α 는 Q11 에서 표현량과 구분됨이 확인되었으므로 "관습 방향" 해석을 유지할 수 있다.

## 3. 자료에 대한 새 사실 (논문 저자 질의 포함)
1. Table 2 D960 열은 문항 2·4·7·11·14·17·18·19 가 CSV 와 반대 극으로 적혀 있다(8−x 로 오차 ≤ 0.13). 2라운드 열은 dry→wet 만 CSV 와 다르다(3.87 vs 3.22, 4.20 vs 3.87, 원인 미상).
2. 평가자는 연주자에 무작위 배정되지 않았다. 평가자 보정 없이 계산한 모든 단위 내 통계(PDF 포함)는 평가자 관대도가 섞여 있다.
3. D960 연주자 ID 는 악장 간 같은 녹음이고, MAESTRO 2004–2018 의 e-Competition 녹음이다(10/12 확인; 8·12 번 미확인). D935 연주자 7명은 2011–2017 녹음이며 D960 연주자와 같은 파일이 없다 → **연주자 ID 는 곡을 넘어 같은 사람이 아니다**(저자 확인 전까지 강한 가설).
4. 반복 평가 1,309쌍의 재검사 잡음은 큰 편(평균 |차| 0.9점)이고 간격이 짧을수록 오히려 조금 크다(1.01 vs 0.88). 잘못 제출 후 재평가는 아니다(모르겠음 0.3%).
5. 자유 서술 1,908건 중 키워드 기준 선호 표현은 약 3%뿐이고 대부분 서술·평가다 — 지시문대로 평가자들이 선호를 억제했다는 쪽과 맞다.
