## E3 · PercePiano D960 같은 단위 사람 연주 쌍 (H3) — 완료

- 자료: D960 2·3악장 846구간(사람 777, Score 69), 단위 69 → 쌍 분석은 단위 64(연주 ≥4), 4,213쌍. 임베딩 847구간 모두 2048 토큰 이내.
- 손 특징: 컨테이너에서 partitura 1.9.0 + parangonar 3.4.0 으로 다시 정렬(847구간, 오류 0, 악보 매치율 ≥0.8 필터).
- 통계: 단위 내 백분위 순위 풀링 Spearman; p = 단위 안 연주자 라벨 셔플 순열 1,000회; q = BH.

**사전 예측 대조 (H3)**
- 예측 1 "페달 차원은 Aria 거리와 양의 상관" → **기각.** dry→wet ρ=0.02(n.s.), clean→blurred 0.03(경계). 청취자가 가장 일관되게 듣는 차원(0.88)을 Aria 거리는 거의 담지 않는다.
- 예측 2 "fast→slow 는 약함" → **방향은 틀리고 크기는 맞음.** Aria 중 가장 큰 상관이 fast→slow(0.15)였지만 여전히 작다(E1: 전역 템포 ×0.8/1.2 가 0.06–0.13 배 움직임과 일관).
- 예측 3 "대응 손 특징 1개 ≥ Aria" → **지지.** 모든 차원에서 손 특징 1개가 Aria 보다 크고, log_tempo 는 0.48.
- 종합: **같은 구간 사람 연주 사이의 지각된 차이에 대해 Aria 코사인 거리는 거의 정보가 없다(ρ ≤ 0.15).** 정렬 손 특징 7개 또는 대응 특징 1개가 훨씬 낫다. Aria 가 보는 '연주'는 기계 vs 사람 축에 집중되어 있다.
- 한계: raw·표준화 모두 같은 패턴. 단위 내 쌍별 거리는 악보 성분을 빼도 같으므로(e_i − e_j = r_i − r_j) 이 결과는 C1 의 잔차 공간에도 그대로 적용된다 → C 의 연주 성분은 손 특징 하이브리드(RQ4)가 처음부터 필요하다는 근거.

## 세 실험을 합친 한 줄
Aria 임베딩은 **기계 vs 사람**(무표정 거리 4–5배, 범위 압축·큰 지터)에는 민감하고, **사람 vs 사람**(전문가가 0.88 신뢰도로 듣는 페달 차이, 템포 차이)에는 거의 둔감하다 — PercePiano 라벨 구조(기계/사람은 가르고 사람끼리는 못 가름)와 닮은꼴이지만, 라벨이 가르는 사람끼리 차이마저 Aria 는 놓친다. C 의 연주 성분은 Aria 잔차만으로는 지각적으로 얇다.

**E1 의 비율 정의, 04 §8 `sensitivity`** (`sc` 는 삭제된 `src/feas/score.py` 의 채점기, `fs.cos_dist` 는 코사인 거리)
```python
def sensitivity(piece):
    sc, res = SC[piece], RES[piece]
    V = sc.vec["aria_std"]
    hh = {}
    for w in range(sc.n_win):
        H = np.stack([V[sc.clean_idx[(p, w)]] for p in sc.humans])
        hh[w] = np.median([fs.cos_dist(H[i], H[j]) for i in range(len(H)) for j in range(i + 1, len(H))])
    man = sc.man
    rid = {r: i for i, r in enumerate(man.row_id)}
    rows = []
    for (c, a), d in man[man.overlap == "in"].groupby(["cond", "alpha"]):
        r = [fs.cos_dist(V[rid[x.row_id]], V[rid[x.clean_row_id]]) / hh[int(x.win_idx)] for x in d.itertuples()]
        rows.append({"조건": f"{COND_KO[c]}" + (f" α={a:g}" if c in ("vel", "tempo") else ""), piece: np.median(r)})
    return pd.DataFrame(rows).set_index("조건")
```
